📺 Sobre Rick and Morty

Rick and Morty é uma série de animação americana de comédia e ficção científica criada por Justin Roiland e Dan Harmon para o bloco de programação noturno Adult Swim do canal Cartoon Network. A série estreou em 2 de dezembro de 2013 e rapidamente se tornou um fenômeno cultural mundial.

A história acompanha as aventuras interdimensionais do gênio cientista alcoólatra Rick Sanchez e seu ingênuo neto Morty Smith, que dividem seu tempo entre a vida doméstica e viagens por diferentes dimensões e planetas.

🌀 Sobre a API

A Rick and Morty API é uma API REST gratuita e de código aberto que fornece dados sobre personagens, localizações e episódios do universo da série. Não é necessário nenhum token ou autenticação para utilizá-la, bastando fazer requisições HTTP diretamente aos endpoints disponíveis.
